# Telegram-бот регистрации заявок в 1С

Бот принимает заявки в Telegram, передаёт их в 1С через HTTP-сервис и позволяет
пользователю отслеживать статус. До подключения 1С проект запускается в `mock`-режиме:
заявки временно хранятся в памяти процесса.

## Возможности первой версии

- команда `/start` и главное меню;
- пошаговое создание заявки;
- выбор категории и приоритета кнопками;
- подтверждение перед регистрацией;
- просмотр собственных заявок;
- просмотр карточки и статуса заявки;
- отмена новой заявки;
- единый клиент HTTP API для последующего подключения 1С.

## Подготовка окружения

Требуется Python 3.12 или новее.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

Создайте бота через `@BotFather`, затем укажите токен в локальном файле `.env`.
Не публикуйте этот файл и токен в GitHub.

## Запуск без 1С

Оставьте в `.env` значение:

```dotenv
BOT_MODE=mock
```

Запустите:

```powershell
python -m tg_bot
```

Mock-данные очищаются после перезапуска процесса.

## Подключение 1С

После публикации HTTP-сервиса измените настройку:

```dotenv
BOT_MODE=onec
ONEC_BASE_URL=http://localhost/tg_project/hs/issue-api/v1
ONEC_API_TOKEN=your_shared_secret
```

Ожидаемый контракт HTTP-сервиса описан в
[`docs/1c_http_api.md`](docs/1c_http_api.md).
